# Installatie

1. Kopieer de map `Eclipse-airbags` naar de `resources` van je FiveM-server.
2. Voeg dit toe aan `server.cfg`:

```
ensure Eclipse-airbags
```

3. Herstart de server, of gebruik `refresh` en daarna `ensure Eclipse-airbags`.

Drempels staan in `config.lua`. De map `stream` hoort bij de resource: daarin zit het airbag-model. Haal die map niet weg.

Een schampschot deukt de kant in waar je raakt. Een harde tik daar laat de band klappen. Na een reparatie gaan de deuken en de klapband weer weg.
