# mallorca_loadscreen

FiveM loading screen voor **Mallorca Roleplay**.

## Install

1. Zet deze map in `resources/[local]/mallorca_loadscreen`
2. In `server.cfg`:

```cfg
ensure mallorca_loadscreen
```

3. Zet andere loadscreens uit.

## Aanpassen

- Achtergrond: `assets/background.png` (1920×1080)
- Logo: `assets/logo.png`
- Teksten/tips: `html/index.html`
- Kleuren: `html/style.css` (`:root` variabelen)
