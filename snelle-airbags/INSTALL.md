# Installatie

1. Kopieer de map `snelle-airbags` naar de `resources` van je FiveM-server.
2. Voeg dit toe aan `server.cfg`:

```
ensure snelle-airbags
```

3. Herstart de server, of gebruik `refresh` en daarna `ensure snelle-airbags`.

Drempels staan in `config.lua`. De map `stream` hoort bij de resource: daarin zit het airbag-model. Haal die map niet weg.
