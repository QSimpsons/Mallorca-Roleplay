# jg-progressbar Progress export

Optioneel: kopieer `Progress.lua` naar je bestaande `jg-progressbar` resource
als andere scripts ook `exports['jg-progressbar']:Progress` aanroepen.

Instructies: zie `ZET-IN-JG-PROGRESSBAR/LEESMIJ.txt` in de repo-root.

`jg-anwb` zelf heeft dit bestand **niet** nodig. `client/progress.lua` valt
al terug op ox_lib als de export ontbreekt.
