INSTALLATIE MALLORCA SPEEDOMETER
================================

1. Map "mallorca-speedometer" in je resources zetten
2. sql/install.sql eenmalig in HeidiSQL uitvoeren
3. In server.cfg:

   ensure oxmysql
   ensure mallorca-speedometer

4. Server herstarten of:
   ensure mallorca-speedometer

Inhoud is alleen tekst: lua, html, css, js, sql.
Geen exe, geen encoded payload, geen externe download.
