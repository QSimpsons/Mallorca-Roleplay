# Mallorca Speedometer

Eenvoudige FiveM voertuig-HUD. Geen externe downloads, geen encoded bestanden.

## Installatie

1. Zet de map `mallorca-speedometer` in `resources`
2. Voer eenmalig uit: `sql/install.sql`
3. In `server.cfg`:

```cfg
ensure oxmysql
ensure mallorca-speedometer
```

## Functies

- Snelheid (fluo oranje)
- Tankmeter + SQL opslag
- Motor / schade
- Pinkers + noodknippers
- Handrem + lichten

## Toetsen

- Pijl links / rechts = pinkers
- Pijl omlaag = noodknippers
