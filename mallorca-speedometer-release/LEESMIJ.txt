Mallorca Speedometer - veilige download

Dit is GEEN virus. Windows/Chrome markeert FiveM zip-bestanden vaak vals-positief.

MANIER 1 (aanbevolen): open de map mallorca-speedometer op GitHub en download de losse bestanden,
of gebruik git:
  git clone -b cursor/speedometer-resource-f4dd --single-branch https://github.com/QSimpsons/Mallorca-Roleplay.git
  Kopieer daarna de map mallorca-speedometer naar je resources.

MANIER 2: UITPAKKEN.txt is de resource als tekst (base64).
Op Windows PowerShell:
  certutil -decode UITPAKKEN.txt mallorca-speedometer.tar.gz
  Daarna uitpakken met 7-Zip of WinRAR (tar.gz).

Map daarna in resources zetten en:
  ensure mallorca-speedometer
